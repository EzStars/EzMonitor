# 毕业论文目录管理说明

本目录按“资料沉淀 + Prompt 管理 + 生成留痕”组织：

- `00-历史资料`：你已有的开题、往届参考、阶段文档归档区
- `01-Prompt管理`：AI 论文生成 Prompt 管理（迭代机制内嵌于 Prompt）
- `02-规范说明`：论文格式规范、模板、写作约束
- `03-生成历史Log`：每次生成结果与对话日志留档
- `04-doc解析输出`：原始 doc/docx 解析后的 Markdown 产物与深度分析

建议每次使用 AI 生成论文内容时，按以下流程执行：

1. 先看 `02-规范说明`，确认格式与禁令要求。
2. 在 `04-doc解析输出` 选择本轮可用来源文档（优先使用最新解析稿）。
3. 在 `01-Prompt管理` 选择当前版本 Prompt，并填入来源文档清单与事实证据卡片。
4. 生成后将输入/输出写入 `03-生成历史Log`。
5. 根据 Prompt 中“迭代回路”规则，记录本轮问题与下一轮修订动作。
